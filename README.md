# cutEer 🎬
محرر فيديو بسيط ومتقدم يعمل بالكامل داخل المتصفح (مناسب للهاتف والـ PC) ومصمم بهوية **الأزرق الفاتح والأسود** وبواجهة مستوحاة من Adobe Premiere Pro.

## خطوات الرفع على GitHub Pages:
1. فك الضغط عن الملف.
2. أنشئ مستودعاً جديداً (Repository) في GitHub باسم `cuteer`.
3. ارفع جميع الملفات (`index.html`, `style.css`, `app.js`, `README.md`, ومجلد `assets`).
4. اذهب إلى **Settings > Pages** واختر الفرع `main` ثم اضغط **Save**.
